# Legacy Filter Mode

## Status

Старый режим фильтрации через Mini App временно поставлен на паузу. Он сохранён в проекте, но активная продуктовая разработка сейчас переключена на новый режим массовой рассылки продаж квартир по Ташкенту.

## Что уже сделано

- Telegram Mini App отправляет фильтр в бот через `tg.sendData()`.
- Бэкенд принимает JSON без `_auth` и сохраняет фильтр пользователя.
- Поддержан мультивыбор по районам и количеству комнат.
- Фильтр хранится в БД как один актуальный набор данных на пользователя.
- Парсер OLX умеет:
  - искать районы Ташкента по названию и ориентирам;
  - распознавать комнаты по нескольким форматам;
  - подтягивать детали со страницы объявления;
  - собирать описание, автора, этаж и дату публикации.

## С какими проблемами столкнулись

- Карточки OLX часто не содержат полные данные по площади и комнатам.
- Район в карточке может быть текстом виден человеку, но оставаться `tashkent` в машинном матчинге.
- Даты и параметры объявления встречаются в разных форматах и не всегда стабильно парсятся с первой попытки.
- Для точного извлечения приходится заходить внутрь объявления, а это заметно увеличивает нагрузку на OLX.
- При частых доработках и перезапусках старые записи в `ads` мешали быстро проверять, начали ли реально доходить уведомления.

## Что было изменено в последнее время

- Усилен словарь районов Ташкента и ориентиров.
- Добавлены дополнительные regex для комнат.
- Усилен парсинг площади, включая fallback со страницы объявления.
- Добавлен fallback-матчинг по району и цене, если площадь не распознана.
- Добавлены сервисные скрипты для очистки `filters` и `ads`.

## Почему режим заморожен

Старый фильтр стал слишком сложным в сопровождении одновременно с задачей по массовой отправке всех продаж квартир по Ташкенту. Чтобы не тормозить разработку, он временно сохранён как отдельная ветка функциональности без активного развития.
